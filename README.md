### 🏛️ Featured Architecture & Flagship Projects

#### 1. 🏥 Patient Management Microservices System
*Enterprise Distributed Architecture (Java 21 · Spring Boot 3 · gRPC · Apache Kafka · AWS CDK · Docker)*

<div align="center">
  <img src="./assets/architecture-diagram.svg" width="100%" alt="Patient Management Microservices Architecture" />
</div>

- **Four Decoupled Microservices:** `Patient`, `Billing`, `Auth`, and `Analytics` built with **Java 21** and **Spring Boot 3**.
- **High-Speed Sync RPCs:** Synchronous inter-service communication handled over **gRPC with Protobuf**, achieving ultra-low network latency.
- **Event-Driven Messaging:** Asynchronous event streaming through **Apache Kafka** (`patient-created`, `billing-records`, `audit-metrics`) for decoupled invoice generation and analytical aggregation.
- **Infrastructure as Code (IaC):** Complete cloud deployment scripted in **AWS CDK** and verified with **LocalStack** (VPC, RDS PostgreSQL, Amazon MSK, Application Load Balancer, and ECS Fargate).
- **Quality Standards:** Validated with OpenAPI/Swagger specifications, Jakarta Bean Validation, **JUnit 5**, **REST-Assured**, and distributed tracing logging.
